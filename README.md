# provs-app
App de check-in verificado para torcedores

## MotionLab (editor de Motion Design)

Abra `motion-editor/index.html` no navegador (sem build, sem dependências).
Camadas (formas, texto, imagem), keyframes com easing, animações prontas, modelos,
gerador aleatório e exportação em vídeo (WebM), PNG e projeto (.json).
